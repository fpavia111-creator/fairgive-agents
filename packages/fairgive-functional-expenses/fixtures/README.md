# Fixtures

One fictional half-year of expense lines, an allocation table for shared costs and the
department-to-function map in the settings. Planted: utilities split 60/20/10, leaving
600 unallocated (allocation_not_100), gala invitations coded to a program
(fundraising_coded_program) and supplies with no department or function
(expense_without_function). Salaries follow their departments, rent is split 70/20/10
and travel names its function directly. `exports/` holds an Aplos transactions export
(Tag as the department).
