# Fixtures

A fictional organization's 2026 gifts, officers and grants paid. Names and addresses
are made up. Planted: a 10,000 contributor with no address (scheduleb_missing_address),
an 8,000 stock gift with no description (scheduleb_noncash_no_description), noncash gifts
of 28,000 in all (schedule_m_likely), a board chair with no hours (officer_missing_hours),
a treasurer with no compensation entered (officer_missing_comp) and a 6,000 grant to an
organization with no EIN (schedulei_missing_ein). A 2025 gift and a 3,000 grant are left
out. This prepares data; it files nothing and is not tax advice.
