# Fixtures

Twelve fictional constituent records; every name, e-mail, phone and address is made up.
Planted: a second record for the same donor with the same e-mail written with capitals and
a +tag (same_email, same_name, same_address), a record with the name written last-first and
the same phone in another format (same_phone, same_name), a misspelt name at the same
address (similar_name, same_address), two people of one household at one address
(same_address only: watch) and two people who share an office e-mail that the settings
list as shared, so they are not paired. `exports/` holds a Raiser's Edge NXT
constituent export.
