# Fixtures

Eight fictional gifts, a fund list with the words that name each restricted purpose, and
two appeals. Names are made up. Planted: a gift whose note names the scholarship fund
coded to general operating (memo_names_restricted_purpose), a capital campaign pledge
payment coded to general (memo_names_restricted_purpose, appeal_fund_mismatch), a gift to
a fund closed in 2019 (fund_inactive), a fund code not in the list (unknown_fund), a
capital appeal gift coded to general with no note (appeal_fund_mismatch) and a note that
designates the gift for a purpose no fund has (memo_says_restricted). One gift uses the
fund's name instead of its code: a person can teach the agent that "General Operating"
means GEN (coding_learn), which waits for a named person to accept it.
